## What I Built

I built a Python and Streamlit Ghost Story Generator. A user enters a spooky topic, chooses a story length, and the app asks an open-weight AI model to write a fictional Halloween story.

## How I Built It

I used Python, Streamlit, and the Qwen2.5-3B-Instruct open-weight model through Hugging Face's hosted inference API. The app sends the user's topic to the model and displays the generated story.

## Why Does Open Innovation Matter?

Using an open-weight model makes it easier to experiment with different models and build an application without tying the project to a single closed model. This version uses hosted inference, so it is not fully offline and the prompt is processed by the inference provider.

## The Spirit of It

I chose the “Ghost in the Machine” theme by turning a simple prompt into an eerie fictional story. The goal is to make it easy for anyone to create a spooky tale from their imagination.
